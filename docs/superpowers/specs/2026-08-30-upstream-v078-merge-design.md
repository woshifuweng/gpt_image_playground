# SSXZ 图片工作台上游 v0.7.8 合并设计

## 目标

将图片工作台从上游 v0.7.3 更新到 v0.7.8，并完整保留 SSXZ 已上线的品牌、接口适配、模型范围和简化交互。合并以官方上游代码为新基底，不在旧版本上继续堆叠补丁。

## 当前基线

- 当前 SSXZ 分支：`codex/ssxz-image-workbench`
- 当前上游基底：v0.7.3
- 目标上游版本：v0.7.8（`f08385c`）
- 当前分支相对目标上游：SSXZ 独有 7 个提交，上游新增 27 个提交
- 当前基线验证：30 个测试文件、402 项测试通过；生产构建通过

## 合并原则

1. 从上游 v0.7.8 创建隔离工作树和新分支。
2. 以功能意图为单位迁移 SSXZ 改动，不整包覆盖上游文件。
3. 上游新增逻辑、数据迁移、测试和更好的通用界面实现优先保留。
4. 仅在 SSXZ 产品边界处重新叠加定制：品牌、入口、默认接口、模型白名单、设置限制和已确认的交互简化。
5. 不写入 API Key、Token 或其他密钥；现有公开构建变量只保留非敏感配置。
6. 不修改正式环境；本轮完成到提交并推送 SSXZ 分支，正式发布需另行确认。

## 必须保留的 SSXZ 能力

- `SSXZ 图片工作台` 品牌、PWA 名称、图标和回到 SSXZ 主站的入口。
- 默认使用 SSXZ 同源图片接口，避免浏览器跨域和暴露真实上游地址。
- 只展示已经在 SSXZ 生产环境验证的图片模型。
- API Key 文案和 SSXZ 相关说明。
- 当前已经确认的控件简化、尺寸说明、任务卡片提示和版本检查行为。
- 旧用户浏览器中的历史任务、配置和 IndexedDB 数据保持兼容。

## 直接吸收的上游能力

- 多预置配置、默认配置和预置保护策略。
- sub2api 异步图片供应商及中断恢复。
- 透明背景的 API 原生与本地后处理双模式。
- 分享链接不携带配置 ID 的隐私修复。
- 中文输入法 Enter 事件兼容修复。
- 服务商选项与 API 配置列表行高、按钮尺寸统一。
- 上游 v0.7.4 至 v0.7.8 的测试、类型和部署脚本修复。

## 验收标准

- 完整测试套件通过，且 SSXZ 默认接口和模型白名单测试仍在。
- TypeScript 与 Vite 生产构建通过。
- 本地页面实际打开并逐项检查：品牌、首页、设置、模型选择、API Key 输入、尺寸选择、任务列表、透明背景和移动端布局。

- Git 工作区干净，提交历史清晰，推送到 SSXZ fork 的独立分支。

## 回滚

原分支和原工作树保持不动。若新版本测试或页面验收失败，停止推送并删除隔离工作树即可；现有可用版本不受影响。
